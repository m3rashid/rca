## 📖 Overview

Website for a coaching academy — pages, animations, contact/quote flows, mailer integration.

## 🏗 Project structure

```
rca/
├── src/
│   ├── components/
│   ├── pages/
│   ├── animations/
│   ├── mailer/
│   ├── models/
│   └── utils/
├── public/

```

## 🛠 Tech stack

`Next.js` · `TypeScript` · `Tailwind`

## 📦 Quick start

```bash
git clone https://github.com/m3rashid/rca.git
cd rca
pnpm install
pnpm dev
```
